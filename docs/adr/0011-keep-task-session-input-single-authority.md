# Keep Task Session input single-authority and compact

Task Session inputs use Messages as the only embedded authority for Feishu conversation text, a minimal Reply Context for reply-target safety, optional non-duplicating Resources and Context Access, and a compact Output Contract near the end of the prompt. Operational counts, task snapshots, the current task label, null fields, empty sections, and the full Pydantic schema stay out of the business prompt; provider-native schemas plus Python validation continue to enforce the final JSON. This trades a self-contained diagnostic envelope for less repetition and anchoring. Codex Task Sessions additionally receive a fixed adapter-level developer instruction to keep tool exploration silent and emit one final JSON object; that provider-specific interaction control does not leak into the backend-neutral Agent Input Contract.
