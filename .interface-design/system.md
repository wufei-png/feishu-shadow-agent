# Operator Console 界面规范

## 使用场景与方向

面向单人值守的飞书 Shadow Agent 操作台。进入页面时，操作者首先判断哪些不确定分流、审批和受阻任务需要处理，再打开对应证据与详情。界面保持冷静、紧凑、可扫描；首页的「待我处理」决策索引是视觉和操作焦点。

使用近白色与石墨色作为浅色和深色画布，以青绿色标识导航选中、交互焦点和成功状态。黄色只表达警告，红色只表达危险或失败。静态界面文案使用中文；API 返回的标识符、错误码和原始内容保留原文，方便排障。

## 主题与色彩

- 主题选项为「跟随系统／浅色／深色」。选择保存在本地；「跟随系统」响应系统配色变化。页面在应用加载前设置根元素主题，避免首屏闪烁。
- 浅色：画布 `#f5f8f8`、面板 `#ffffff`、抬升层 `#f0f5f5`、主要文字 `#17272b`、青绿 `#137b70`、警告 `#925d10`、危险 `#ac404b`。
- 深色：画布 `#10171a`、面板 `#192226`、抬升层 `#202d31`、主要文字 `#ebf2f1`、青绿 `#75d5be`、警告 `#e8be70`、危险 `#f18a91`。
- 组件只引用 `styles.css` 中的语义变量。表面靠细边框和小幅色阶区分层次，不使用装饰性渐变或投影。

## 字体、层级与密度

- 正文优先 `Noto Sans CJK SC`，标题优先 `Bahnschrift`，数据优先 `JetBrains Mono`；均保留系统回退字体。动态数字使用等宽数字特性。
- 首页标题 34px，其他页面主标题 28px，二级标题 18px；主要内容 13–14px，标签和辅助文字 11–12px。主要文字、次要文字、弱提示分别使用三个文字色阶，配合字重建立层级。
- 以 4px 为基础间距单位。工作区主内边距 24px，面板 18px，列表项与控制区常用 12–16px，区块间距 16px。小组件圆角 6px，面板圆角 10px。
- 首页先展示发送待核实或失败、待审批、处理阻塞或失败三项可直达的待办决策，再展示任务总量等背景信息。发送入口打开相关发送状态，任务入口包含所有任务状态。状态色只用于有明确含义的数值或标签。

## 可复用组件

| 组件 | 规范 |
| --- | --- |
| 按钮 | 最小高度 40px、水平内边距 12px、圆角 6px、13px 半粗字；危险等语义变体仅改变文字色。 |
| 侧栏导航 | 行高至少 42px、水平内边距 10px；当前项使用抬升层底色与 3px 青绿内侧标记。 |
| 列表行 | 最小高度 70px、内边距 12px、圆角 6px；选中时使用青绿边框与 3px 内侧标记。 |
| 状态标签 | 最小高度 24px、水平内边距 8px、胶囊圆角、12px 半粗字和等宽数字。 |
| 面板 | 18px 内边距、10px 圆角、细边框；工作区面板之间相隔 16px。 |
| 待办决策入口 | 桌面最小高度 116px、内边距 16px、32px 数值；窄屏纵排时最小高度 88px。 |
| 主题选择 | 原生选择器，最小高度 40px、圆角 6px，始终放在运行状态栏。 |

## 交互与响应式

- 可交互元素提供悬停、按下、键盘焦点和禁用状态。键盘焦点使用 2px 青绿轮廓，外偏移 2px；`prefers-reduced-motion` 下移除位移和过渡。
- 1180px 以下工作区多列布局折为单列；900px 以下侧栏改为顶部横向滚动导航，工作区内边距改为 16px；560px 以下决策入口和数据区改为单列。
- 表单输入、空状态和错误提示继续使用同一语义色体系，不因页面不同创建新的配色或尺寸。
